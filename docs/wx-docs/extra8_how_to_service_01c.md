# # 如何完成商家授权
 在完成 服务商账号的创建 后，接下来则是进行业务系统与第三方平台的开发对接，在联调测试完成之后即可进行第三方平台的全网发布。在完成全网发布之后，该第三方平台已经具备为商家提供服务的基础条件了。大概的步骤如下：

## # 一、授权逻辑介绍
 服务商为商家提供服务的基础是「服务商」获得「商家」的授权。
 换句话说就是，商家需要将其公众号、服务号、小程序、微信小店、带货助手、视频号助手等账号授权给第三方平台，服务商才可以代商家进行相关操作。
 完成一次完整的授权，需要服务商与商家的配合，相关流程如下，操作截图可查看 授权与解除授权。
 服务商获得商家授权后再使用 authorizer_access_token 调用接口即可。（注意，别用错了 token。）

## # 二、操作指南

### # 1、服务商进行权限集的配置
 权限集配置的操作路径为：微信开放平台 - 第三方平台 - 详情 - 开发配置 - 权限集配置，详情可查看 服务商配置权限集操作指南。

### # 2、服务商进行授权链接构建
 详情可查看：授权流程技术说明。

### # 3、服务商进行授权链接处理
 完成权限集配置之后，服务商需进行授权链接构造。
 构造的授权链接，可以依据业务实际情况进行放置，方便商家方便顺利地完成授权即可。

### # 4、商家扫码授权给服务商
 商家需将其名下的公众号、服务号、小程序、微信小店、带货助手、视频号助手等账号授权给服务商的第三方平台账号之后，服务商方可代商家调用接口完成业务开发和管理。操作截图可查看 授权与解除授权。
 授权的注意事项
 对于互斥的权限集，一个账号只可以将互斥的权限集授予一个服务商；对于非互斥的权限集，一个账号最多同时授权给 15 个服务商；
 关于权限集的介绍可查看 权限集说明。
 对于服务商而言，一个第三方平台可以被无数个账号授权。
 服务商无法单方面解除授权，需商家才可以解除授权。
