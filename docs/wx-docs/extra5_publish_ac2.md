# # 申请全网发布
 开发者在完成测试后，可以申请全网发布。审核通过后，第三方平台业务即可上线，可向所有符合要求的公众号/小程序进行登录授权。
 未通过全网发布的第三方平台，仅「授权测试公众号/小程序列表」内的公众号或小程序才可进行授权，以进行测试。

## # 第三方平台测试说明
 初次创建第三方平台时，可填写用于测试的域名或 URL，在完成测试之后再修改为正式环境的配置信息。
 也可以初次创建时就使用正式环境的配置，然后使用「测试公众号/小程序」进行授权测试，待测试完成之后再提交全网发布。
 此外，在测试阶段还需要针对专用测试公众号的消息推送进行适当处理，详情说明请参考全网发布接入检测说明。
 当业务已发布上线，仍想进行测试，可将相关开发配置修改为测试环境的地址（例如，微信会同时将 ticket 推送至测试授权事件 URL 以及全网发布生效的授权事件 URL），只要不进行全网发布，则不会影响现网。待测试完成之后，再进行全网发布即可。

## # 第三方平台全网发布操作

### # 1. 进入全网发布入口
 前往「第三方平台详情 - 开发信息 - 开发资料 - 全网发布」。

### # 2. 进入全网发布接入检测
 如遇到检测不通过的项，建议按照全网发布接入检测说明进行修正后再进行全网发布。

### # 3. 等待检测结果
