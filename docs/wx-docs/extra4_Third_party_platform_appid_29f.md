# # 平台概述
 微信开放平台-第三方平台（简称第三方平台），由微信团队面向所有通过开发者资质认证的第三方开发者提供的官方平台。在得到公众号或小程序管理员授权后，基于该平台，第三方服务商可以通过调用官方接口能力，为商家提供公众号代运营、小程序代注册、代开发等服务。

## # 三、第三方平台分类与选择

### # 3.1 第三方平台分类

#### # 定制化型第三方平台
 当你不需要以服务商身份使用第三方平台接口能力，只需生成票据用于标记商家小程序是由该服务商开发的，那么可以选择创建该类型的账号。该类型的账号仅有一个 AppID 用以作为服务商账号 ID，没有 Secret，无法生成 Token，不可调用官方任何接口能力。

#### # 平台型第三方平台
 这是官方推荐选择的类型，该类型的服务商可基于第三方平台接口能力，在获取商家扫码授权后，为商家提供代开发、代运营公众号和小程序服务。想要为商家实现批量化服务，例如批量运营公众号、批量代开发小程序等，则需要选择该类型的账号。

### # 3.2 平台型第三方平台核心优势
 安全可靠的授权
 服务商无需管理多个商家的账号密码或者 AppID 和 Secret；商家只需要将部分权限授权给服务商即可，且可以随时解除授权。
 可基于官方接口能力批量为商家提供服务
 获得商家授权后，即可通过官方接口能力批量管理，大大提升效率。可将小程序代码上传托管到模板库中，基于一个模板发布多个小程序。

### # 3.3 平台型第三方平台应用场景
 1）为商家提供综合的解决方案，整体打包公众号或小程序的产品开发、运营等；
 2）为小程序商家提供小程序代开发服务、代运营服务；
 3）为小商店商家提供小商店增值服务；
 4）为公众号商家提供专门优化图文消息视觉样式和排版的工具，或专门定制的 CRM 用户管理功能等。
 注意：在技术上，第三方平台是通过获得公众号或小程序的接口能力的授权，然后代公众平台账号调用各业务接口来实现业务的，因此，第三方平台在调用各接口时，必须遵循公众平台运营规范，详见《微信公众平台运营规范》。
