# # 如何成为服务商
 本文将介绍如何注册成为公众号、服务号、小程序、微信小店、带货助手、视频号助手服务商。成为了服务商之后如何为商家提供服务可查看 如何为商家提供服务。

## # 一、关于服务商账号
 微信开放平台 - 第三方平台账号即为「公众号、服务号、小程序、微信小店、带货助手、视频号助手服务商的账号」。在创建了第三方平台账号之后，服务商即可基于第三方平台开放的能力结合公众号、服务号、小程序、微信小店、带货助手、视频号助手的接口能力为商家提供服务。
 补充说明
 1）第三方平台账号的审核无需缴费，但开放平台账号的认证（即开发者资质认证）需要交 300 元认证费。
 2）一个已完成开发者资质认证的开放平台账号，可创建 5 个平台型服务商第三方平台账号。

## # 二、创建服务商账号准备
 第三方平台账号创建依赖如下信息，需提前准备：

| 信息 | 说明 |
|---|---|
| 官方网站 | - 创建时必填 - 即，服务商应当有对外可用的官网，且该官网提供的服务描述与申请的第三方平台账号名称、简介、图标均有所关联。 |
| 平台图标 | - 提交审核前必上传 - 图标必须为当前服务商所有，不可使用其他企业的图标作为第三方平台账号图标。 |

## # 四、如何选择不同类型账号
 平台型第三方平台账号
 这是官方推荐选择的类型，该类型的服务商可基于第三方平台接口能力，在获取商家扫码授权后，为商家提供代调用公众号、服务号、小程序、微信小店、带货助手、视频号助手的接口能力。
 想要为商家实现批量化服务，例如批量运营公众号、批量代开发小程序等，则需要选择该类型的账号。
 定制化型第三方平台账号
 当你不需要以服务商身份使用第三方平台接口能力，只需生成票据用于标记商家小程序是由该服务商开发的，那么可以选择创建该类型的账号。
 该类型的账号仅有一个 APPID 用以作为服务商账号 id，没有 secret，无法生成 token，不可调用官方任何接口能力。该类型的服务商通常不基于第三方平台能力为商家提供服务。
